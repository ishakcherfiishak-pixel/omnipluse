# OmniPulse — دليل النشر على استضافة Google (Firebase Hosting)

## قبل النشر
- هذه الحزمة واجهة أمامية ثابتة، وليست خدمة اجتماعية مكتملة بقاعدة بيانات.
- رفع الفيديو والرسائل والإعجابات الحالية محلية على المتصفح. لا تُشارك بين الزوار أو الأجهزة.
- لا ترفع فيديوهات لا تملك حق نشرها. احصل على موافقة أصحاب المحتوى قبل النشر.

## نشر الموقع عبر Firebase Hosting
Firebase Hosting خدمة استضافة من Google. لا يمكن نشر مجلد HTML كامل مباشرةً داخل Google Sites كأنه موقع تقليدي؛ استخدم Firebase Hosting لنشر هذه الملفات.

1. فك ضغط ZIP على الكمبيوتر.
2. ثبّت Node.js من الموقع الرسمي: https://nodejs.org/ ثم افتح Terminal أو CMD جديدًا.
3. ثبّت أدوات Firebase: `npm install -g firebase-tools`
4. سجّل الدخول: `firebase login`
5. أنشئ مشروعًا من https://console.firebase.google.com/ ثم انسخ معرّف المشروع.
6. افتح CMD داخل المجلد الذي يحتوي `firebase.json` وملفات HTML.
7. اربط المجلد بالمشروع: `firebase use --add` واتبع التعليمات لاختيار مشروعك.
8. انشر: `firebase deploy --only hosting`
9. سيعرض Firebase رابط الموقع المنشور. افتحه واختبر كل الصفحات على الهاتف والكمبيوتر.

## الملفات الرئيسية
- `index.html`: الصفحة الرئيسية.
- `shorts.html`: قسم الشورتس.
- `cinema-original.html`: قسم الفيديوهات العادية/السينما.
- `stories.html`: القصص والرسائل.
- `quran.html`: القرآن الكريم والورد.
- `settings.html`: الإعدادات.
- `firebase.json`: إعدادات Firebase Hosting.
- `manifest.webmanifest` و`icon.svg`: بيانات الأيقونة وإمكانية التثبيت كاختصار.
- `404.html`: صفحة الخطأ.

## ما يلزم قبل إطلاق عام حقيقي
1. إضافة تسجيل دخول حقيقي وصلاحيات ملكية الفيديو.
2. قاعدة بيانات للمنشورات والتعليقات والإعجابات والرسائل.
3. تخزين فيديو سحابي وقواعد أمان وحدود أحجام ورفع.
4. مراجعة الخصوصية والإبلاغ والحظر وسياسة المحتوى.

لا تضع مفاتيح سرية أو كلمات مرور في ملفات HTML أو JavaScript عامة.


## التحديث الأخير: تسجيل الدخول وتمرير الشورتس
- تمت إضافة زر وقائمة «تسجيل الدخول» كتجربة محلية على المتصفح. لا تدخل كلمة مرور حقيقية؛ لا يوجد نظام مصادقة آمن في هذه النسخة.
- صفحة `shorts.html` تعرض كل فيديو في شاشة كاملة تقريبًا مع تمرير رأسي وميزة الالتقاط بين الفيديوهات، ودعم السهمين لأعلى/أسفل وPage Up/Page Down.
- نشر الفيديوهات والإعجابات والجلسة التجريبية محلية وليست مشتركة بين المستخدمين.


## تسجيل الدخول بكلمة مرور وصورة الحساب
- عند فتح أي صفحة، تظهر بوابة تسجيل الدخول/إنشاء الحساب وتمنع استخدام واجهة الصفحة حتى تسجيل الدخول.
- يجب إنشاء حساب أولًا باسم مستخدم وكلمة مرور لا تقل عن 8 أحرف؛ كلمة المرور تُحفظ كقيمة مشتقة باستخدام PBKDF2 في هذا المتصفح، وليست مخزنة كنص واضح.
- بعد الدخول، استخدم زر «حسابي» أعلى اليسار لتعديل الاسم ورفع صورة الحساب (PNG/JPG/WebP/GIF حتى 3MB).
- هذا نموذج محلي على المتصفح فقط، وليس مصادقة آمنة لخدمة عامة: يمكن مسح بيانات المتصفح أو تجاوز حماية الواجهة تقنيًا، والحساب لا ينتقل إلى جهاز آخر. قبل الإطلاق العام اربط Firebase Authentication وFirestore/Storage، واجعل صلاحيات الكتابة والحذف في قواعد الخادم.
- افتح الموقع عبر HTTPS (مثل Firebase Hosting) أو خادم محلي؛ هذا مطلوب لدعم Web Crypto بصورة صحيحة.


## تحديث القائمة الجانبية والهاتف
- أضيف زر ☰ لإظهار القائمة الجانبية أو إخفائها. على الهاتف تفتح كقائمة منزلقة مع طبقة خلفية، وعلى الكمبيوتر يمكن إخفاؤها لتوسيع مساحة المحتوى.
- تم تحسين المسافات وأحجام عناصر الرأس ومناطق الفيديو للشاشات الصغيرة.
- تظهر الفيديوهات التي تم رفعها في نفس المتصفح/النطاق لجميع الجلسات المحلية، مع إظهار اسم الناشر للفيديوهات الجديدة، وتظهر خاصية الحذف لصاحب الفيديو المسجل محليًا.
- مهم: IndexedDB محلي ولا يزامن الفيديوهات بين أجهزة أو متصفحات مختلفة. لكي يرى كل المستخدمين فيديوهات بعضهم عبر الإنترنت، يلزم تخزين سحابي وقاعدة بيانات وصلاحيات على الخادم؛ لا يمكن تحقيق ذلك بتعديل HTML وحده.
